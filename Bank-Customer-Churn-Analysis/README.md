# Bank Customer Churn Analysis — Power BI Project

## Project Overview
This project analyzes bank customer data using Microsoft Power BI to explore customer churn, customer characteristics, and factors associated with churn. The dashboard is designed to help users review churn patterns and customer-level details.

## Dashboard Preview
Dashboard screenshots will be added to the `Screenshots/` folder.

## Dashboard Sections
- **Customer Overview:** Key metrics and customer distribution.
- **Churn Analysis:** Customer churn patterns and churn-related visuals.
- **AI Insights:** Key Influencers and Decomposition Tree visuals to explore factors associated with churn.
- **Customer Details:** Customer-level information for deeper analysis.

## Tools Used
- Microsoft Power BI
- Power Query for data preparation and transformation
- DAX for measures and KPIs
- Data modeling and interactive visualizations

## How to View
1. Download the Power BI `.pbix` file from `Dashboard_file/` once it has been uploaded.
2. Open it in Microsoft Power BI Desktop.
3. If prompted, update the source path to the dataset stored in `Dataset/`.
